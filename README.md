## みんなのアニマル図鑑について
自慢のペットやお気に入りの動物を自由に登録し、みんなで共有できるアニマル図鑑アプリケーションです。自分の投稿はマイページから編集・削除できます。

## 開発の背景と工夫
バリデーションを実装し、必須項目や画像形式をチェックすることで、正しいデータのみ登録できるようにしました。
ログイン状態（`@auth`）とゲスト状態でヘッダーの表示（ユーザー名表示やログアウトボタン）が綺麗に切り替わるようにしています。
マイページではログインユーザー自身の投稿のみを表示し、他ユーザーの投稿と区別できるようにしています。編集と削除も、自分の投稿だけ操作できるようにしています。
